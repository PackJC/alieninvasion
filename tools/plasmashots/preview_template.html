Reading the bench

Timing, spread, layering and colour come straight from each file. Brightness and bloom are approximate, because the game adds HDR and eye adaptation on top. Judge final glow strength in Workbench.

A few values have no engine documentation: the three ConeAngle numbers, how the RND spreads apply, and StretchMultiplier. The bench reads them the way vanilla's own effects suggest.

Light: Vanilla is the orange muzzle light DayZ spawns for illuminateWorld=1. Matched is a light in the cell's own colour.

In game

Each cartridge colour plays its own effect: geb_PlasmaCartridge green, _Arc blue, _Lance lime, _Void violet. The cell's muzzleFlashParticle in data/config.cpp picks it.

Changing one

  1. Tune colours and sizes in tools/plasmashots/shots.py and run it.
  2. Rebuild this page with tools/plasmashots/preview.py.
  3. Repack the mod and check the effect in Workbench.
